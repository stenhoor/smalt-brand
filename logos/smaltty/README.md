# smaltty logos

The mark is the Grain, turned: smaltdb's Grain rotated half a turn, so the notch and the chip sit at the bottom left.
The block is smalt (`#003399`) and the chip kiln (`#E5622F`), the family's colour: TypeScript is the language of
everything smalt. The owner's pick, 2026-11-12 (DECISIONS.md, "smaltty: a product").

| File | Use |
| --- | --- |
| `lockup.svg`, `lockup-on-dark.svg` | Mark + wordmark, outlined. README headers, docs, slides. |
| `wordmark.svg`, `wordmark-on-dark.svg` | Wordmark alone: `alt` in smalt, `ty` in `#A33A12` (light) or `#FF8A5C` (dark). |
| `grain-mark.svg`, `grain-mark-on-dark.svg` | The mark alone. Dark version: `#9DB4F5` block, `#FF8A5C` chip. |
| `app-icon.svg` | Smalt tile with the mark knocked out. App and PWA icons, avatars. |
| `favicon-32.svg`, `favicon-16.svg` | Browser tabs. The same drawing at both sizes. |

The `-on-dark` files are transparent with light ink, so they look blank in light previews.

Generated by `scripts/brand_assets.py`. Don't recolour, rotate, outline or add effects: unturned, or with a smalt
chip, it is smaltdb's Grain.
