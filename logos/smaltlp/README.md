# smaltlp logos

The Aim mark: one solid arrow at 45°, pointing at the chip: heading straight for the best answer. The arrow is smalt
(`#003399`), and the chip is jade (`#0A7C76`), the kit layer's colour. The owner's pick, 2026-11-17 (DECISIONS.md,
"smaltlp").

| File | Use |
| --- | --- |
| `lockup.svg`, `lockup-on-dark.svg` | Mark + wordmark, outlined. README headers, docs, slides. |
| `wordmark.svg`, `wordmark-on-dark.svg` | Wordmark alone: `alt` in smalt, `lp` in `#086A65` (light) or `#10C2B9` (dark). |
| `aim-mark.svg`, `aim-mark-on-dark.svg` | The mark alone. Dark version: `#9DB4F5` arrow, `#10C2B9` chip. |
| `app-icon.svg` | Smalt tile with the mark knocked out. App and PWA icons, avatars. |
| `favicon-32.svg`, `favicon-16.svg` | Browser tabs. The same drawing at both sizes. |

The `-on-dark` files are transparent with light ink, so they look blank in light previews.

Generated by `scripts/brand_assets.py`. Don't recolour, rotate, outline or add effects.
