# smaltcy logos

The Graph mark: three nodes and the edges between them, at 0°, 45° and 90°. The nodes and edges are smalt (`#003399`),
and the node a query returns is the chip, in cobalt magenta (`#B0249F`), the language layer's colour. The owner's pick,
2026-11-14 (DECISIONS.md, "smaltcy").

| File | Use |
| --- | --- |
| `lockup.svg`, `lockup-on-dark.svg` | Mark + wordmark, outlined. README headers, docs, slides. |
| `wordmark.svg`, `wordmark-on-dark.svg` | Wordmark alone: `alt` in smalt, `cy` in `#981C89` (light) or `#F57FE6` (dark). |
| `graph-mark.svg`, `graph-mark-on-dark.svg` | The mark alone. Dark version: `#9DB4F5` graph, `#F57FE6` chip. |
| `app-icon.svg` | Smalt tile with the mark knocked out. App and PWA icons, avatars. |
| `favicon-32.svg`, `favicon-16.svg` | Browser tabs. The same drawing at both sizes. |

The `-on-dark` files are transparent with light ink, so they look blank in light previews.

Generated by `scripts/brand_assets.py`. Don't recolour, rotate, outline or add effects.
