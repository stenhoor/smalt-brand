# smaltfl logos

The Twin mark: two waves in step, the old sign for water, and a chip where they arrive. The waves are smalt
(`#003399`) and the chip deep cerulean (`#0E7FAE`), the user-tool layer's colour. The waves are curved, an exception to
the family's 0°, 45° and 90° rule, as smaltql's Star is one.

| File | Use |
| --- | --- |
| `lockup.svg`, `lockup-on-dark.svg` | Mark + wordmark, outlined. README headers, docs, slides. |
| `wordmark.svg`, `wordmark-on-dark.svg` | Wordmark alone: `alt` in smalt, `fl` in `#0B6A91` (light) or `#5CBDE8` (dark). |
| `twin-mark.svg`, `twin-mark-on-dark.svg` | The mark alone. Dark version: `#9DB4F5` waves, `#5CBDE8` chip. |
| `app-icon.svg` | Smalt tile with the mark knocked out. App and PWA icons, avatars. |
| `favicon-32.svg`, `favicon-16.svg` | Browser tabs. The same drawing at both sizes. |

The `-on-dark` files are transparent with light ink, so they look blank in light previews.

Generated by `scripts/brand_assets.py`. Don't recolour, rotate, outline or add effects.
