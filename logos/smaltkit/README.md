# smaltkit logos

The Case mark: a kit case with a handle, a lid and a base. The case is smalt (`#003399`), and the latch that holds the
lid to the base is the chip, in jade (`#0A7C76`), the kit layer's colour. The owner's pick, 2026-11-14 (DECISIONS.md,
"smaltkit: a brand").

| File | Use |
| --- | --- |
| `lockup.svg`, `lockup-on-dark.svg` | Mark + wordmark, outlined. README headers, docs, slides. |
| `wordmark.svg`, `wordmark-on-dark.svg` | Wordmark alone: `alt` in smalt, `kit` in `#086A65` (light) or `#10C2B9` (dark). |
| `case-mark.svg`, `case-mark-on-dark.svg` | The mark alone. Dark version: `#9DB4F5` case, `#10C2B9` chip. |
| `app-icon.svg` | Smalt tile with the mark knocked out. App and PWA icons, avatars. |
| `favicon-32.svg`, `favicon-16.svg` | Browser tabs. The same drawing at both sizes. |

The `-on-dark` files are transparent with light ink, so they look blank in light previews.

Generated by `scripts/brand_assets.py`. Don't recolour, rotate, outline or add effects.
