# smaltai logos

The Agent plug mark: your agent as the plug, a face with two prongs on top. The face and prongs are smalt (`#003399`); one
eye is smalt and the other is the chip, in blue-leaning violet (`#6E4BC2`), the colour of smaltai's layer, alongside the
others. The owner's pick, 2026-11-22 (DECISIONS.md, "smaltai").

| File | Use |
| --- | --- |
| `lockup.svg`, `lockup-on-dark.svg` | Mark + wordmark, outlined. README headers, docs, slides. |
| `wordmark.svg`, `wordmark-on-dark.svg` | Wordmark alone: `alt` in smalt, `ai` in `#6141AE` (light) or `#B8A1F2` (dark). |
| `plug-mark.svg`, `plug-mark-on-dark.svg` | The mark alone. Dark version: `#9DB4F5` face, `#B8A1F2` chip. |
| `app-icon.svg` | Smalt tile with the mark knocked out. App and PWA icons, avatars. |
| `favicon-32.svg`, `favicon-16.svg` | Browser tabs. The same drawing at both sizes. |

The `-on-dark` files are transparent with light ink, so they look blank in light previews.

Generated by `scripts/brand_assets.py`. Don't recolour, rotate, outline or add effects.
