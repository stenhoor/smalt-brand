# Architecture Decision Records

Records for family work whose product has no repository of its own yet. When the product's repository is created, its
own `docs/adr/` index lists the record too.

**One numbering for all smalt ADRs** (owner's rule, 2026-11-09): records in every smalt repository share one sequence,
continuing smaltdb's ([0001–0022](https://github.com/stenhoor/smaltdb/tree/main/docs/adr)) and smaltts's
([0023](https://github.com/stenhoor/smaltts/tree/main/docs/adr)). A new record takes the next number after the highest
in any repository, open PRs included.
