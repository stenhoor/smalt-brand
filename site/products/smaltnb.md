# <Mark product="nb" :size="40" /> smaltnb

<StageBadge />

**Small. Alternative. Notebooks.** TypeScript notebooks for smaltdb.

smaltnb is inspired by Jupyter and marimo: a notebook for working through data step by step, scripted in TypeScript.
Notebooks are designed to be reactive: change a cell and the cells that depend on it run again. One notebook will mix TypeScript, SQL
on smaltdb and smaltdf dataframe cells, with charts from the smalt [kits](/products/kits).

**Status:** in early development, not yet published. The notebook format and its dependency graph work; running
notebooks is next. See [its status page](https://stenhoor.github.io/smaltnb/guide/status).
