[smalt-brand repository](https://github.com/stenhoor/smalt-brand), which has the source files, the design tokens and
the full [brand book](https://github.com/stenhoor/smalt-brand/blob/main/BRAND.md).

## Using the names and logos

- Write every name in lowercase, as one word: smaltdb, never SmaltDB.
- Don't recolour, stretch, rotate or redraw the logos.
- Use a badge to say you use a smalt product; don't use a logo in a way that suggests smaltworks made or endorses
  your project unless it did.
