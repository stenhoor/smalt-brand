# Get involved

smaltworks happens in the open, on GitHub. There's no mailing list to join and no form to fill in.

## Ask, suggest, show what you made

Start a conversation in **[GitHub Discussions](https://github.com/stenhoor/smalt-brand/discussions)**: questions,
ideas, and things you've built with the smalt family.

## Report a bug or request a feature

Open an issue on the project it's about:

- [smaltdb](https://github.com/stenhoor/smaltdb/issues), and its plugins:
  [io](https://github.com/stenhoor/smaltdb-io/issues), [external](https://github.com/stenhoor/smaltdb-external/issues),
  [parquet](https://github.com/stenhoor/smaltdb-parquet/issues)
- [smaltql](https://github.com/stenhoor/smaltql/issues) · [smaltdf](https://github.com/stenhoor/smaltdf/issues) · [smaltui](https://github.com/stenhoor/smaltui/issues) ·
  [smaltbi](https://github.com/stenhoor/smaltbi/issues) · [smaltnb](https://github.com/stenhoor/smaltnb/issues) ·
  [smaltkit](https://github.com/stenhoor/smaltkit/issues)

## Contribute

Pull requests are welcome on every project. Start small: a fix, a test, a clearer sentence in the docs. Each
repository's README says how to build and test it. Code is under the [MIT licence](/open-source).

## Build on it

Write a [plugin](/products/plugins), use smaltdb in your own app, or show you're
[powered by smalt](/brand#powered-by-badges).

## Join the core team

The [core team](/community/team) grows from contributors. If you've been helping out and want to do more, say so in
Discussions.

Everyone taking part follows the [code of conduct](/community/code-of-conduct).
