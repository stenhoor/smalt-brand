## One engine, many ways to use it

Every smalt tool runs on the same engine, **smaltdb**, in the browser you already have. Query it with smaltql, the SQL you know, or with
the smaltdf dataframe language; explore it in smaltui, report on it in smaltbi, work through it in smaltnb notebooks, and run it
as pipelines in smaltfl. smaltty checks the TypeScript you write against smaltdf and smaltts as you type it. smaltcy speaks Cypher to graphs,
on its own engine and stores for now, with smaltdb's storage to come.
There is no second engine for dataframes and no server to set up.

## Small data deserves good tools

Big data gets the headlines. We believe most of the data people actually work with fits on the machine in front of them: a
spreadsheet that outgrew itself, a folder of CSV files, an export from a system of record, a few Parquet files. We
think that work deserves fast, capable tools that start in a browser tab, with nothing to install and nothing to
provision.
