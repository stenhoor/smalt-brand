Docs for the agents that use our languages and tools

Beside the people docs, every site publishes Markdown made for AI agents: complete, exact and tested, generated from the same sources as the pages, so the two can't disagree. It follows the llms.txt proposal (an index at the site root, a Markdown twin of every page) and adds one agent guide per product.

# smaltql: agent guide (0.9.0)## Use- Install: `npm install --save-exact @smaltworks/smaltql@0.9.0`- `const db = await open('app')`, then `await db.query(sql, params?)` → rows as objects.- In memory (Node, tests): `import '@smaltworks/smaltql/register'`, then `Database.openMemory()`.## Rules- Dialect: SQLite's. Types are SQLite's affinities. Dates are text; lists and structs are JSON text.- Not supported: `ORDER BY` inside an aggregate call → `SMALT_UNSUPPORTED`. Aggregate an ordered subquery instead.- Aggregates ignore NULL, except `count(*)`. Empty input: `count` → 0, `total` → 0, others → NULL.## Grammarselect-core = "SELECT" [ "DISTINCT" | "ALL" ] result-column { "," result-column }              [ "FROM" table-or-subquery ] [ "WHERE" expr ]              [ "GROUP BY" expr { "," expr } [ "HAVING" expr ] ] ;## Functions| name | args | returns | NULL / empty || `sum(X)` | number | int or real | NULL for none || `median(X)` | number | real | NULL for none |## Example (tested)```sqlSELECT region, sum(qty) AS qty FROM sale WHERE qty > 1 GROUP BY region;```→ `[{ region: 'north', qty: 5 }, { region: 'south', qty: 4 }]`## Errors| code | when | fix || `SMALT_UNSUPPORTED` | a feature smaltql doesn't have | the rule above names the alternative |
