smaltml: machine learning on the hardware you have

smaltml is classic machine learning for smaltdb data, running on the hardware a browser can reach: WebGPU where it is available, the CPU where it isn't. It is pluggable libraries, not part of the engine: smaltml is the brand, and each library is a plainly named part of it. Still being shaped, so these words are a first pass. Colour is left open for now.
