Five minutes to a query

From nothing to a working query, in your browser. Three steps, each one runnable right here.

STEP 1
Install
npm i @smaltworks/smaltql, or skip it: the playground below needs nothing.
STEP 2
Open a database
open('app'): the engine starts in a worker; data lives in OPFS.
STEP 3
Query it
Create a table, add rows, ask a question. Run it below, then change it.
