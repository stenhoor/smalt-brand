aggregate

Plan language · Operations

One row per group of its input, with aggregate calls computed over each group. What SQL's GROUP BY and smaltdf's groupBy().agg() both build.

Syntax

plan-op: read
plan-op: shape
plan-op: combine
plan-op: write
aggregate ▾ (1 of 2)
aggregate (2 of 2)
agg-call ▾ (expanded in place)

Keywords are the JSON keys and their fixed values; square boxes are rules, and open in place. Every operation is a JSON object with "op"; every expression one with "k".

Fields

FieldTypeRequiredMeaning
inputplan-opyesThe rows to group.
keysgroup-key[]yesOne expression and collation per key; none for one group over all rows.
aggsagg-call[]yesOne aggregate call per output column.
carryplan-expr[]yesInput columns carried to the output from one row of the group.
ordered"first"noGive the groups in the order of each group's first row.

Output

Its keys, then one column per aggregate call, then the carried columns.

Errors

SMALT_PLAN when the plan doesn't validate: an unknown aggregate, a column out of range, a version this engine doesn't read.
