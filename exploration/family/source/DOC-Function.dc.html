groupBy

Frames · Aggregation

One row per group, with aggregates computed over each group. Runs in the engine as one grouped aggregation.

Frame.groupBy(
  ...keys: (string | Expr)[],
  options?: { maintainOrder?: boolean }
).agg(...exprs: Expr[]) → Frame                          source ↗ · since 0.9.0

Parameters

ParameterTypeDefaultDescription
keysstring | Expr—Columns or expressions to group by; one row per distinct combination.
maintainOrderbooleanfalseKeep groups in the order their keys first appear.
exprsExpr[]—Aggregates over each group, and the keys themselves.

Returns

Frame: the keys first, then one column per expression, named after its input or its alias.

Errors

SMALT_ERROR when an expression in agg is neither an aggregate nor a key.

Note Group order is not promised unless maintainOrder is set: sort after grouping when order matters.

Examples

Total quantity and mean price per region, from the four orders in the working demo below:

table('orders')  .groupBy('region')  .agg(col('qty').sum(), col('price').mean().alias('avg_price'))  .sort('region');
