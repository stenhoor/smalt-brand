smaltts: smaltdb, straight from TypeScript

Under ADR 0015, smaltdb has no language built in: an app that wants neither SQL nor dataframes works with the engine's raw plan API and schema operations. smaltts is a thin, typed TypeScript API over them, with structured flows for apps and for layers built on the engine. It joins the family on the same system: the wordmark, a smalt body with one chip, a “Small. Alternative. ___.” tagline and a short line.
