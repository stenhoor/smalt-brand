family · colour by layer · proposal

One colour per layer, not per product

Each layer of the stack takes one colour; the mark tells products in a layer apart. Five colours cover any number of products. The layer colours reuse hues already checked against the status colours: smalt for the engine, magenta for the languages, jade for the kits, cerulean for the user tools, violet for smaltai, which runs alongside. Violet sits close to smalt (CIELAB distance 21), so it goes to smaltai, which doesn't touch the engine layer, and not to the languages, which sit on it. Ochre, leaf green and graphite, the picks that sat near a status colour or read as disabled, would retire. smaltml, smaltai and smaltfl marks are placeholders; smaltfl has no mark yet.
