1Editor: smaltkit/editor, with SQL or TypeScript highlighting and completion from the playground's schema.
2Engine: smaltkit/engine, loaded from the site's own copy (never a CDN), in a worker, once per page, on the first Run.
3Data: each playground starts from the page's setup block in an in-memory database; Reset brings it back.
4Results: smaltkit/grid for rows, smaltkit/pretty for plans; errors show their code, linked to its page.
5TypeScript: smaltkit/typescript (smaltty) strips types so smaltdf code runs as written.
6Share: the code goes in the link's fragment, never to a server. Open in smaltui carries it to the workbench.
