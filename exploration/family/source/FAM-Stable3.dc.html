Releases the way Git tools draw them

Git graph tools rarely draw the tag itself. Mermaid and GitGraph.js attach the version as a text label to a commit, and mark special commits with a different node: a filled double circle for a merge, a rectangle for a highlight. GitHub pairs an open pull request icon with a merged one. Gitflow tags each release on main where the release branch merges in. Our badge already carries the label, "Stable · 1.0", so the sign only needs to show a fixed point with work still coming in.
