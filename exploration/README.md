# Exploration archive

Every board shown during the brand work, in the order it was presented. [`DECISIONS.md`](../DECISIONS.md) records what was picked from each round and why; this folder shows what was on the table.

Each board is kept twice:

- `png/`: a rendered snapshot at full size (1440 px wide), for viewing.
- `source/`: the board's source (`.dc.html`, the Claude design-canvas format) and the canvas layout (`canvas.json`), for reference. They need the canvas runtime to render, so they don't open as plain web pages.

These are records, not current assets. Older boards use the earlier "Alternate" wording, name other engines, and show colours and marks that were not chosen. For the current brand, use [`BRAND.md`](../BRAND.md), [`logos/`](../logos/), [`badges/`](../badges/) and [`tokens/`](../tokens/).

## How the snapshots were made

Each `.dc.html` was rendered headless in Chromium at its board size, with the same Google Fonts files the boards load (Geist, Geist Mono, Martian Mono, IBM Plex Sans and Mono, Newsreader, Inter Tight, JetBrains Mono, Bricolage Grotesque, DM Mono).
